# 🎯 Jogo de Adivinhação em Python

Projeto desenvolvido em **Python** com o objetivo de praticar conceitos fundamentais da linguagem por meio de um jogo de adivinhação executado no terminal.

## 📖 Sobre o projeto

O programa sorteia aleatoriamente um número inteiro entre **1 e 10**.

O jogador deve tentar descobrir qual número foi sorteado. A cada tentativa, o programa informa se o palpite foi muito alto ou muito baixo.

O jogo continua até que o jogador acerte o número.

Ao final, o programa informa quantas tentativas foram necessárias.

## ⚙️ Como funciona

Durante o jogo:

- Se o palpite for maior que o número sorteado, o programa exibe `Muito alto!`
- Se o palpite for menor, exibe `Muito baixo!`
- Se o jogador acertar, exibe `Acertou!`
- Cada palpite é contabilizado como uma tentativa
- O jogo termina somente quando o número correto é descoberto
